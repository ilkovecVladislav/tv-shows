# StyleX authoring

1. Read the official StyleX LLM resources:
   https://stylexjs.com/docs/llm-resources
2. Follow the StyleX version installed in this repository and its actual
   Vite/build configuration.
3. Use documented StyleX APIs and supported patterns. Do not guess APIs or
   transfer assumptions from other CSS-in-JS libraries.
4. Keep styles statically analyzable as required by StyleX.
5. Reuse existing project tokens, themes, and conventions when present.
6. Do not introduce another styling system or ad-hoc global CSS unless
   explicitly requested.
7. Verify uncertain behaviour against the official documentation.
