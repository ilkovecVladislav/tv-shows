# TV Shows Explorer (TVmaze) — план реализации

## Context

Проект `ts-shows` — чистый Vite-шаблон (React 19 + TS + StyleX + ky, всё уже настроено в `vite.config.ts` / `.oxlintrc.json`). Строим с нуля приложение поиска сериалов по [TVmaze API](https://api.tvmaze.com/search/shows?q=...): поиск с debounce, отмена устаревших запросов, карточки с пагинацией по 3, фильтр по жанрам чипсами, состояния загрузки/ошибки/пусто. Без useQuery — fetch-логика на AbortController. Все компоненты свои, дизайн минималистичный, десктоп, палитра pastel (`#cdb4db`, `#ffc8dd`, `#ffafcc`, `#bde0fe`, `#a2d2ff`). **UI-тексты на русском.**

## Структура (по docs/architecture/architecture.md)

Роутера нет и не заводим (один экран — no premature abstraction). `App.tsx` — тонкий root, рендерит страницу.

```
src/

├── types/show.ts                  # NEW: Show { id, name, genres, premiered, rating, image?, summary? }
├── hooks/useDebouncedValue.ts     # NEW: дженерик-хук debounce (400мс)

├── App.tsx                        # REWRITE: <ShowsPage />

├── App.css, assets/{hero.png,react.svg,vite.svg}   # DELETE

    ├── index.ts / ShowsPage.tsx / types.ts / usePresenter.ts / stylex.ts
    ├── utils.ts                   # PAGE_SIZE=3, collectGenres()
    ├── hooks/useShowSearch.ts     # стейт-машина запроса: idle|loading|success|error + AbortController
    ├── SearchBar/                 # контролируемый инпут: иконка, clear-кнопка (полная анатомия папки)
```

Каждая папка компонента: `index.ts`, `ComponentName.tsx` (только JSX, default export), `types.ts` (+ `ReturnType<typeof usePresenter>`), `usePresenter.ts` (≤120 строк), `stylex.ts`. Импорты только через `index.ts`. Ничего не кладём в `src/components/` (нет кросс-страничного переиспользования).

## Логика данных

- **useShowSearch(query)**: debounce(400мс) → trim; пустой запрос → `idle`, без запроса. `useEffect` с AbortController: ky с `signal`, при смене — abort; `AbortError` молча игнорируется (в т.ч. StrictMode double-mount). Возвращает `{ status, shows, error, searchedQuery, retry }`.
- **usePresenter** (ShowsPage): query-стейт → useShowSearch; `genres = collectGenres(shows)`; фильтрация по выбранному жанру и срез страницы — **производные значения без эффектов**: `safePage = min(page, totalPages)`, `effectiveGenre` сбрасывается сам, если жанра нет в новой выдаче. Клик по жанру/«Все» — обычные обработчики + `setPage(1)`.
- **Сервис**: `GET search/shows?q=`; нормализация каждого элемента (проверка `show.id`/типов, фильтрация мусора, strip HTML из summary, `premiered → год`, `image.medium`), невалидные элементы пропускаются.
- Все состояния отрисованы: idle (подсказка), loading (спиннер), error (сообщение + «Повторить»), success-empty («Ничего не найдено по "…"»), success.

## Дизайн (StyleX only)

Минимализм: светлый фон с мягким pastel-градиентом, тёмно-сливовый текст, белые карточки с тонкой тенью и радиусом, grid 3 колонки (1 страница = 1 ряд). Чипы жанров — пастельные (цвет жанра детерминированно из палитры), выбранный — залит. Пагинация по центру. Спиннер через `stylex.keyframes`. Десктоп-only, без media queries. Системный шрифт. Тексты RU: «Поиск сериалов…», «Загрузка», «Что-то пошло не так», «Ничего не найдено» и т.п.

Перед написанием стилей загружу скиллы `modern-web-guidance` (обязателен для клиентского HTML/CSS) и `stylex`.
